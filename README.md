# आपलं धामणगाव रेल्वे

Dhamangaon Rly sathi local quick-commerce website. Ek file (`index.html`), konti build / install garaj nahi.

## GitHub Pages var live karne
1. GitHub var navin repository banva (jase `dhamangaon-rly`), **Public** thevaa.
2. **Add file → Upload files** madhe ya zip madhli sarv files (`index.html`, `.nojekyll`, `README.md`) taka. **Commit changes** kara.
3. **Settings → Pages**. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**. Save kara.
4. 1–2 minute nantar link tayar: `https://<tumche-username>.github.io/dhamangaon-rly/`

## Navin data / badal
- Page madhe ⚙️ Admin (PIN `1234`, lagech badla) madhun products takta yetat, pan te fakt tya phone var save hotat.
- Sarv customers na dakhavayche asel tar `index.html` madhe `seed()` function madhe brands ani products badla, mag file GitHub var navin upload kara.

## Mahatvache
- WhatsApp number: Admin → Settings madhe taka (kinva `seed()` madhe `wa`).
- Admin PIN fakt browser madhe check hoto, to khara security nahi.
